# AI integrations overview: ticket triage service

A retailer's customer-support platform receives support tickets through a REST API. This sample is the runnable part of the AI integrations overview guide: an HTTP service that classifies each incoming ticket by category and priority with a typed LLM call (`model->generate()` bound to a `Triage` record), validates the model's answer with constraint annotations, and routes the ticket to a support queue using plain Ballerina logic. Model failures and invalid responses are reported as `502 Bad Gateway`, and invalid payloads are rejected with `400 Bad Request` before the model is called.

For the full walkthrough, see the guide: [AI integrations overview](https://ballerina.io/learn/ai-integrations-overview/).

## Prerequisites

- Ballerina 2201.13.0 (Swan Lake Update 13) or later (this package is set to distribution 2201.14.0)
- An OpenAI API key

## Configure

Copy the example configuration file and set your OpenAI API key.

```
$ cp Config.toml.example Config.toml
```

```toml
openAiApiKey = "<YOUR_OPENAI_API_KEY>"
```

## Run

```
$ bal run
```

The service listens on port `8080`.

## Try it

Classify a ticket. Because the classification is generated by an LLM, your results will differ.

```
$ curl -X POST http://localhost:8080/tickets/triage \
    -H "Content-Type: application/json" \
    -d '{"subject": "Charged twice", "body": "I was charged twice for order ORD-1042 and need the second charge refunded."}'
{"category":"billing", "priority":"medium", "summary":"The customer was charged twice for order ORD-1042 and requests a refund of the duplicate charge.", "queue":"billing"}
```

Send a ticket with an empty body. The payload fails the constraint check and is rejected without calling the model.

```
$ curl -i -X POST http://localhost:8080/tickets/triage \
    -H "Content-Type: application/json" \
    -d '{"subject": "Refund", "body": ""}'
HTTP/1.1 400 Bad Request
```

If `openAiApiKey` is set to an invalid value, the service logs `Failed to classify the ticket` and returns `502 Bad Gateway`.

## Test

The tests cover the deterministic logic (routing rules, constraints, and binding to `Triage`) and do not call the model. They use the placeholder key in `tests/Config.toml`.

```
$ bal test
```
