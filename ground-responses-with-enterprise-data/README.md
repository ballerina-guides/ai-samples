# Ground responses with enterprise data

An HR policy assistant built as a retrieval-augmented generation (RAG) pipeline in Ballerina. At startup, the service loads the Markdown policy documents in `policies/`, chunks them with `ai:MarkdownChunker`, adds the document title and section headings to each chunk's metadata, and indexes them in an in-memory vector knowledge base. For each question, it retrieves the most similar chunks, drops those below a minimum similarity score, asks an LLM for a typed answer that cites the excerpts it used, and returns the answer together with the policy documents and sections it is based on, or a "not found" answer when the policies do not cover the question.

This sample accompanies the [Ground responses with enterprise data](https://ballerina.io/learn/ground-responses-with-enterprise-data/) guide.

## Prerequisites

- Ballerina 2201.13.0 (Swan Lake Update 13) or later
- An OpenAI API key (used for both the embedding model and the LLM)

No vector database is needed: the sample uses `ai:InMemoryVectorStore`, so the documents are ingested again each time the service starts.

## Configure

Copy `Config.toml.example` to `Config.toml` and set your OpenAI API key.

```toml
openAiApiKey = "<YOUR_OPENAI_API_KEY>"
```

The other configurable values (`policyFiles`, `maxChunkSize`, `maxOverlapSize`, `ingestOnStartup`, `port`, `topK`, `minSimilarity`) have defaults; see `Config.toml.example`.

## Run

```
$ bal run
```

The policy documents are ingested (the ingestion stage in `ingestion.bal`, run from the module's `init` function) before the HTTP listener in `service.bal` starts on port 8080.

```
time=... level=INFO module=ai_samples/hr_policy_assistant message="Ingested policy documents" documents=3 chunks=12
```

## Try it

A question the policies answer:

```
$ curl -X POST http://localhost:8080/hr/ask \
    -H "Content-Type: application/json" \
    -d '{"question": "How many unused annual leave days can I carry forward?"}'
{"answer":"You can carry forward up to 5 unused annual leave days to the next calendar year. You must use them before 31 March, or they are forfeited.", "answerFound":true, "sources":[{"document":"leave-policy.md", "title":"Leave policy", "sections":["Carry forward"]}]}
```

A question the policies do not cover:

```
$ curl -X POST http://localhost:8080/hr/ask \
    -H "Content-Type: application/json" \
    -d '{"question": "What is the parking policy at the head office?"}'
{"answer":"I could not find this in the HR policies. Contact HR for help.", "answerFound":false, "sources":[]}
```

A blank question is rejected with `400 Bad Request` without calling any provider:

```
$ curl -i -X POST http://localhost:8080/hr/ask \
    -H "Content-Type: application/json" \
    -d '{"question": "   "}'
```

Answers are generated by an LLM, so your results will differ.

## Test

```
$ bal test
```

The tests cover chunking and source metadata, question validation, score filtering, and citation checks. They use `tests/Config.toml`, which sets a placeholder API key and `ingestOnStartup = false`, so they do not call OpenAI.
