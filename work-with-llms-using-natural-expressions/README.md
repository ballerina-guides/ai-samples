# Use natural expressions in an integration

An HTTP service for a travel-booking platform that suggests tourist attractions for a country and an interest. The resource validates the request, calls an LLM with a natural expression (`natural (model) { ... }`), binds the response to a closed `Attraction[]` record type, validates the result with constraint annotations, and maps failures to `400 Bad Request` or `502 Bad Gateway`.

This sample accompanies the [Use natural expressions in an integration](https://ballerina.io/learn/work-with-llms-using-natural-expressions/) guide.

## Prerequisites

- Ballerina 2201.13.0 (Swan Lake Update 13) or later
- An OpenAI API key

> Natural expressions are an experimental feature. This package enables it through `experimental = true` in `Ballerina.toml`, so the `--experimental` flag is not needed.

## Configure

Copy `Config.toml.example` to `Config.toml` and set your OpenAI API key.

```toml
openAiApiKey = "<YOUR_OPENAI_API_KEY>"
```

To try the sample without your own key, change the model initialization in `service.bal` to `check ai:getDefaultModelProvider()` and run the `Configure default WSO2 Model Provider` command in the Ballerina VS Code extension (after logging in to WSO2 Copilot). The default model provider is subject to rate limits.

## Run

```
$ bal run
```

## Try it

Because the content is generated by an LLM, your results will differ.

```
$ curl "http://localhost:8080/attractions?country=Sri%20Lanka&interest=Surfing&count=3"
[{"name":"Arugam Bay", "city":"Pottuvil", "highlight":"Regarded as Sri Lanka's premier surf spot, Arugam Bay offers consistent waves and a vibrant surf culture."}, ...]
```

An out-of-range `count` is rejected without calling the model.

```
$ curl -i "http://localhost:8080/attractions?country=Sri%20Lanka&interest=Surfing&count=50"
HTTP/1.1 400 Bad Request
...
count must be between 1 and 10
```

## Test

The tests cover the validation logic only and do not call the model. `tests/Config.toml` provides a placeholder key.

```
$ bal test
```
